# پنل من

داشبورد شخصی آفلاین برای گوشی: سلامت (وزن و PAI)، عادت‌ها، تقویم و تسک‌ها، پلنر فردا، اهداف، مالی و یادداشت. همهٔ داده‌ها فقط روی خود گوشی ذخیره می‌شوند.

## اجرا روی کامپیوتر

```bash
npm install
npm run dev
```

بعد آدرس `http://localhost:5173` را باز کن.

## انتشار روی GitHub Pages و نصب روی گوشی

۱. در GitHub یک مخزن جدید بساز (مثلاً با نام `panel`). مخزن خصوصی هم کار می‌کند، به شرط اینکه حسابت Pages خصوصی را پشتیبانی کند؛ در غیر این صورت عمومی بساز. فقط کد برنامه منتشر می‌شود، نه داده‌ها.

۲. داخل همین پوشه:

```bash
git init -b main
git add .
git commit -m "first version"
git remote add origin https://github.com/USERNAME/panel.git
git push -u origin main
```

۳. در صفحهٔ مخزن: **Settings ← Pages ← Source** را روی **GitHub Actions** بگذار. بعد از چند دقیقه برنامه در `https://USERNAME.github.io/panel/` در دسترس است.

۴. آدرس را در Chrome اندروید باز کن، از منوی سه‌نقطه **Add to Home screen** یا **Install app** را بزن. حالا آیکون روی صفحهٔ گوشی است و بدون اینترنت هم کار می‌کند.

هر بار که کد را push کنی، نسخهٔ جدید خودکار منتشر می‌شود و برنامهٔ روی گوشی دفعهٔ بعد که باز شود به‌روز می‌شود. داده‌ها با به‌روزرسانی پاک نمی‌شوند.

## پشتیبان‌گیری

تنظیمات ← گرفتن پشتیبان. هر هفته یک بار انجامش بده؛ اگر یادت برود، صفحهٔ «امروز» یادآوری می‌کند.

## خروجی برای تحلیل

تنظیمات ← ساخت فایل تحلیل. این فایل را به Claude بده تا الگوهای رفتاری را پیدا کند.

## ساختار کد

| مسیر | محتوا |
|---|---|
| `src/db` | پایگاه دادهٔ Dexie و نوع داده‌ها |
| `src/lib` | تاریخ شمسی، تعطیلات، منطق عادت‌ها، تسک‌ها، مالی، اهداف، پشتیبان و انیمیشن (anime.js) |
| `src/ui` | اجزای مشترک: برگهٔ پایینی، پیام، تاریخ‌گزین، دکمه‌ها |
| `src/pages` | صفحه‌های برنامه |
